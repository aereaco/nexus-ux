Labs Category 6 Reactive Scopes

Reactive Scopes & Query Rules

NEG query rules (@rule(param) { ... }) providing responsive queries, container queries, authentication gating, and runtime platform inspection.

@media

Reactive viewport media queries (e.g. @media('(min-width: 768px)')).

@container

Reactive container dimension queries for component-level responsiveness.

@auth

Role and session gating directly in the DOM state stack.

@os

Platform detection (macos, windows, linux, ios, android).

@view

Exposes width, height, isPortrait, and isLandscape signals.

@native

Verifies presence of native mobile or desktop app shell bridge.
