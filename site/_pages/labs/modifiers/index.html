Labs Category 15 Event Modifiers

Event Modifiers & Filters

Pipeline event modifiers that attach directly to event directives (e.g. data-on-click_outside or @input_debounce.250) to intercept, throttle, filter, and coordinate interactions.

_debounce
Timing

Delays execution until specified milliseconds have elapsed since the last invocation.

_delay
Timing

Delays handler execution by a fixed millisecond timeout before firing.

_document
Target

Attaches event listener to document root rather than the local HTMLElement.

_drag
Pointer

Injects delta movement coordinates ($drag.dx, $drag.dy) into pointer handlers.

_hold
Gesture

Fires only when user presses and holds the pointer for the specified millisecond duration.

Open Lab →
_keys
Keyboard

Filters keyboard events by key code or combination (:enter, :escape, :space, :ctrl, :shift).

_morph
Morph

Morphs return string from evaluation directly into the element using morphDOM diffing.

_once
Lifecycle

Executes event listener exactly once, automatically unbinding itself afterwards.

_outside
Outside

Fires handler only when pointer click or tap occurs outside the element boundary bounds.

_prevent
Default

_self
Target

Executes handler only if event.target is the element itself, ignoring child bubbled events.

_stop
Propagation

Calls event.stopPropagation() to isolate events and prevent bubbling up the DOM hierarchy.

_throttle
Rate Limit

_window
