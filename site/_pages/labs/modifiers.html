Labs Category 15 Event Modifiers

Event Modifiers & Filters

Pipeline event modifiers that attach directly to event directives (e.g. data-on-click:outside or @input:debounce.250) to intercept, throttle, filter, and coordinate interactions.

:outside

Fires handler only when pointer click/tap occurs outside element bounds.

:debounce.<ms>

Delays execution until specified idle duration elapses.

:throttle.<ms>

Limits execution rate to once per specified millisecond budget.

:prevent & :stop

Calls e.preventDefault() and e.stopPropagation() respectively.

:hold.<ms>

Triggers handler only after press-and-holding for specified milliseconds.

Key Filters (:enter, :escape)

Restricts keyboard events to specific keys or modifier combinations.
