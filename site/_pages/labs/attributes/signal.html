Engine Architecture & Memory Pattern

Located in src/modules/attributes/signal.ts, the signal directive parses JSON object literals into Vue 3-compatible fine-grained reactive state scopes combined with SignalHeap (SharedArrayBuffer-backed storage) and Rust-inspired borrow validation.

  • Zero-Copy Zero-Serialization (ZCZS): Direct references to live signals without serialization boundary overhead.
  • Hierarchical DOM Cascading: Properties resolve hierarchically from immediate element → parent elements → shadow hosts → #global.
  • Deterministic Teardown: State runners are bound to DOM lifetime and automatically dereferenced when the element unmounts.
