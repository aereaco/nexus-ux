Core Architectural Pillars

Engineered from the ground up for maximum browser performance, zero memory churn, and pure HTML-first expressiveness.

Declarative HTML-First

DOM-as-State composition without imperative scripting

Application logic, state bindings, dynamic templates, and animations are expressed directly in HTML markup. No build step required to run; templates parse natively in the browser's DOM parser.

Implementation Features
  • 30 Native Attribute Directives: data-signal, data-bind, data-for, data-if, data-show, data-on, data-flow, and more.
  • Constructable CSSStyleSheets: Direct CSSOM integration via document.adoptedStyleSheets and data-stylesheet.
  • Single Observer Context: Exactly one universal MutationObserver orchestrating all DOM insertions, diffing, and deterministic teardowns.

Zero-Copy Zero-Serialization

Strictly eliminates JSON serialization and memory copy overhead

State is held in shared memory references and typed heaps. Web Workers and main thread communicate via SharedArrayBuffer, completely avoiding expensive JSON.stringify and postMessage copies.

Implementation Features
  • SignalHeap & SharedArrayBuffer: Atomic typed-array state stores with multi-threaded autoscale topology tiers.
  • Live Proxy Memory Graphs: Arrays and objects mutated in-place; Reflect traps eliminate object re-allocations.
  • Rust-Inspired Borrowing: Strict ownership tracking ensures optimal memory safety and deterministic lifecycle cleanup.

Fine-Grained Reactive Signals

Surgical DOM updates with automatic dependency tracking

Reactivity graphs track precise signal dependencies. Modifying a single value updates only the exact text node or attribute mapped to it, without re-rendering component trees or virtual DOM diffs.

Implementation Features
  • 4-Phase Atomic Execution Loop: Capture → Evaluate → Resolve → Paint guarantees zero dropped animation frames.
  • Frame Budget Yielding: MessageChannel microtask scheduler yields to the browser when computations exceed 8ms.
  • Element-Bound Effects: elementBoundEffect attaches directly to DOM nodes, automatically tearing down effects when removed.

Nexus Expression Grammar (NEG)

Intuitive attribute syntax with scoped rules and pipeline modifiers

NEG provides a clean, expressive grammar executed inside DOM Proxy scopes. Supports scoped rule queries, global signals, event modifier pipelines, and built-in sprite utilities natively.

Implementation Features
  • 6 Reactive Scopes: @media, @container, @auth, @os, @view, and @native for contextual responsive layouts.
  • 15 Pipeline Event Modifiers: :prevent, :stop, :outside, :debounce.250, :throttle, :morph, key filters, and more.
  • 14 Injected Sprites: $el, $(selector), $animate, $sql, $sw, $push, $mcp accessible directly in expressions.
